GET  /iserver/contract/{{conid}}/info-and-rules   ->  used to check available order types for a given CONID
    i.e. https://localhost:5000/v1/api/iserver/contract/265598/info-and-rules?isBuy=true
    i.e. https://api.ibkr.com/v1/api/iserver/contract/265598/info-and-rules?isBuy=true

GET  /iserver/contract/{{conid}}/algos   ->  used to check available IBALGO order types for a given CONID
    i.e. https://localhost:5000/v1/api/iserver/contract/265598/algos?addDescription=1&addParams=1
    i.e. https://api.ibkr.com/v1/api/iserver/contract/265598/algos?addDescription=1&addParams=1

Link = https://www.interactivebrokers.com/docs/web-api/v1/endpoints/orders/place-order | https://www.interactivebrokers.com/docs/web-api/api-reference/trading/trading-orders/submit-new-order

NOTE on 400 Errors:
-------------------
This error suggests your JSON body is not formatted correctly (double-check the commas & brackets) or you're missing a required field like price | auxPrice | quantity | etc.
{
    "error": "Bad Request: Missing order parameters",
    "statusCode": 400
}

Prices now must by typed as floating point integers. Using a string for price / auxPrice will give a 400 error. NOTE: ForecastEx contracts are tradable in Web API

A1. Pre-trade allocation orders
Financial Advisors with IBKR have the ability to use Pre-trade allocations (i.e. Advisor Groups & Profiles) - https://www.interactivebrokers.com/en/software/pdfhighlights/PDF-AdvisorAllocations.php
Rather than allocating an order to just a single U-account, Financial Advisors may decide to allocate new orders to an Allocation Group or Profile. This will split-up one order across multiple U-accounts (upon execution). This may be useful for Financial Advisors looking to achieve the same average price for a particular position, across multiple customer accounts. In both TWS API & Web API- Financial Advisor accounts have the ability to create pre-trade allocation groups programmatically, as well as place new orders to those allocation groups.

Send an order ticket above, however use URL = POST /iserver/account/{faGroup}/orders instead as the URL. NOTE that the GET /iserver/account/allocation/group endpoint can be used to return a list of valid faGroups.

B. Model Portfolio orders
Send an order ticket above, however use URL = POST /iserver/account/{modelCode}/orders instead as the URL. NOTE that the GET /iserver/account/allocation/models endpoint can be used to return a list of valid modelCodes.

        {
            "quantity": 110,                        //quantity or cashQty, depending on alloc_type

            #"outsideRTH": false,
            "isModel": true,
            "conid": "268084",
            "side": "BUY",
            "jsonPayload": {
                "allocation_profile": {
                    "alloc_type": "SHARE",          //SHARE or CASH
