cURL - CP Gateway
==================
Initialize (IServer) Brokerage Session
curl -k -X POST "https://localhost:5000/v1/api/iserver/auth/ssodh/init" -H "accept: application/json" -H "Content-Type: application/json" -d "{\"publish\":true, \"compete\":true}"

Brokerage Accounts
curl -k -X GET "https://localhost:5000/v1/api/iserver/accounts" -H "accept: application/json"

Allocation Models
curl -k -X GET "https://localhost:5000/v1/api/iserver/account/allocation/models" -H "accept: application/json"

Suppress Order Questions
curl -k -X POST "https://localhost:5000/v1/api/iserver/questions/suppress" -H "accept: application/json" -H "Content-Type: application/json" -d "{\"messageIds\":[\"o163\",\"o354\",\"o382\",\"o383\",\"o451\",\"o10164\",\"o10223\",\"p6\",\"o10153\",\"o10331\"]}"

Get Preset
curl -k -X POST "https://localhost:5000/v1/api/fa/fa-preset/get" -H "accept: application/json" -H "Content-Type: application/json" -d "{\"reqID\":1000, \"subscriptionKey\":\"\"}"

Set Preset
